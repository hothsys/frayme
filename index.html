ffmpeg not found

ffmpeg is required for video recovery. Scanning and analysis work without it, but you won't be able to recover damaged files.

1
Install ffmpeg

Download and install ffmpeg for macOS:

ffmpeg.org/download → or via Homebrew: brew install ffmpeg
2
If already installed, update your PATH

Frayme couldn't find ffmpeg on your PATH. If you've already installed it in a non-standard location, add it to your shell profile:

export PATH="/path/to/ffmpeg/bin:$PATH"

Add that line to ~/.zshrc or ~/.bash_profile, then restart Frayme.

3
Restart Frayme

After installing or updating your PATH, stop and restart python3 app.py — the ffmpeg badge will turn green.

Status Guide

No moov Video data exists but the moov atom (metadata index) is missing or unreadable. Players can't seek or open it; recovery rebuilds the index or transplants one from a healthy donor.
Corrupt Container or header structure is invalid or zeroed. Likely needs raw H.264 NAL extraction or a donor transplant to recover usable video.
Truncated Recording or transfer stopped early, cutting the file short. Partial footage may still be recoverable.
Empty Zero-byte file or too small to contain any video. The filename survived, but the contents did not.
Error Could not be read (permissions, I/O error, or unsupported variant). Inspect the file manually.
